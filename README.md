# Discover London ON

A Flutter city-guide app for London, Ontario — nicknamed "The Forest City" —
built for iOS and Android. Store name: **London ON**.

## Features

- Discover home screen: gradient hero, search, category buttons, and stacked
  highlight sections
- Neighbourhood guides (Downtown London, Old East Village, Wortley Village,
  Byron, Old North, North London, East London, White Oaks) with real local
  landmarks and photos
- Category browsing — Art, Sport, Running Groups, Live Events, Food, Groceries,
  History, Outdoors
- Popular Places to Eat, Popular London Events (annual festivals with dates),
  London creators to follow, and Ontario public holidays
- Grocery & international food markets with addresses (Costco, Walmart, No Frills,
  Dollarama, T&T, Superking, London-Asian Foods)
- Light / Dark / System appearance, remembered between launches
- "Get Directions" opens the device's maps app
- Real photos for landmarks (Wikimedia Commons, credited in-app)

## Getting started

```sh
flutter pub get
flutter run
flutter analyze
flutter test
```

Requires Flutter 3.47+.
