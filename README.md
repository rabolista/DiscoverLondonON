# Discover London ON

A Flutter travel-discovery app for London, Ontario — nicknamed "The Forest City" —
built for iOS and Android.

## Features

- Discover home screen with search, categories, and quick highlights
- Neighbourhood guides (Downtown London, Wortley Village, Byron, Old East Village,
  Old North, North London, East London, White Oaks) with real local landmarks
- Popular places to eat, local creators to follow, and Ontario public holidays
- Category browsing (Art, Sport, Live Events, Food, History, Outdoors)
- "Get Directions" deep links into the device's maps app

## Getting Started

```sh
flutter pub get
flutter run
```

## App identifier

Both the iOS and Android targets use the bundle/application ID
`com.rabski.TravelDiscovery`.
